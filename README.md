# Python Flask App with Docker

This is a simple Python Flask web application packaged inside a Docker container.  
The application exposes two routes and runs on **port 8080**.

---


## 📁 Dockerfile Overview

- Uses `amazonlinux` base image  
- Installs Python3 & pip  
- Installs dependencies from `requirements.txt`  
- Copies the Flask application  
- Exposes port `8080`  
- Runs the Flask server
